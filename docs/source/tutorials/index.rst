Tutorials
=========

This section contains step-by-step guides to SAETASS: the basic ones teach its first steps, and the advanced ones cover topics that longer studies need.

These tutorials are written as Jupyter Notebooks, allowing you to see the code, explanations, and outputs all in one place.

Basic tutorials
---------------

The first four introduce the basics and build on each other, so follow them in order. The other two show the calculators of energy losses and of non-thermal emissions.
